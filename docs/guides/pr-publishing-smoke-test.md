# Pull request publishing smoke test

Use this documentation-only change to verify the prepared publishing workflow.

1. Prepare an operation with this file explicitly selected.
2. Review the repository, feature branch, base branch, checks, and proposed text.
3. Approve the exact operation in the developer terminal.
4. Confirm the returned pull request targets `main` and includes only this file.
5. Repeat publishing with the same operation ID and confirm the same PR is returned.

Keep the test pull request open for inspection until the test owner decides its outcome.
